# राजस्थान शाला परीक्षा परिणाम एवं डिजिटल अंकतालिका पोर्टल
### (Rajasthan Multi-Class School Result & Digital Marksheet Portal)

यह एक सम्पूर्ण, प्रोडक्शन-रेडी **मल्टी-क्लास स्कूल रिजल्ट मैनेजमेंट और डिजिटल अंकतालिका (Report Card) सॉफ्टवेयर** है, जिसे राजस्थान शिक्षा विभाग और शाला दर्पण के आधिकारिक परीक्षा नियमों के अनुसार तैयार किया गया है।

---

## 🌟 मुख्य विशेषताएँ (Key Features):

1. **वास्तविक लॉगिन व बहु-विद्यालय प्रणाली (100% Real Authentication):**
   * कोई भी विद्यालय/शिक्षक अपने ईमेल, UDISE कोड और पासवर्ड से स्वतंत्र खाता बना सकता है।
   * प्रत्येक विद्यालय का अपना अलग सुरक्षित डेटाबेस और यूनिक सर्च लिंक (`?school=school-id`) होता है।

2. **कक्षा-वार परिणाम प्रबंधन (Class 3, 4, 6, 7, 8, 9, 11):**
   * प्राथमिक (कक्षा 3 व 4): 5 विषय / सामान्य स्कूलों में 4 विषय (खाली विषय स्वतः गायब)।
   * उच्च प्राथमिक (कक्षा 6, 7 व 8): 6 विषय (3 परख + अर्धवार्षिक + वार्षिक = 200 प्रति विषय, कुल पूर्णांक 1200) + सह-शैक्षणिक क्षेत्र।
   * माध्यमिक (कक्षा 9): 7 विषय + सूचना प्रौद्योगिकी (FOIT), शारीरिक शिक्षा, समाजोपयोगी कार्य (SUPW), कला शिक्षा व राजस्थान इतिहास।
   * उच्च माध्यमिक (कक्षा 11): कला, विज्ञान, वाणिज्य, कृषि संकाय के अनिवार्य व ऐच्छिक सैद्धांतिक/प्रायोगिक विषय + जीवन कौशल व स्वर्णिम भारत।

3. **सुरक्षित छात्र सर्च (Class + Roll No + Date of Birth):**
   * छात्र केवल अपनी कक्षा चुनकर, रोल नंबर और जन्मतिथि (DOB) दर्ज करके अपना परीक्षा परिणाम देख सकते हैं।

4. **आधिकारिक डिजिटल अंकतालिका (A4 Print-Ready):**
   * केंद्र में **REPORT CARD / प्रगति पत्र** शीर्षक और नीचे एक पंक्ति में **सत्र व रोल नंबर**।
   * **लाइट ब्लू/पेस्टल थीम** और **सेंटर-अलाइन्ड (Center Aligned)** टेबल।
   * **जन्मतिथि (DOB):** संख्यात्मक `DD/MM/YYYY` एवं शब्दों में (उदा. `03/05/2017 (तीन मई दो हजार सत्रह)`).
   * **ई-वेरिफाइड बारकोड:** संस्था प्रधान एवं कक्षा अध्यापक के नाम व सत्यापन कोड युक्त बारकोड।

5. **डैशबोर्ड में पूर्ण नियंत्रण:**
   * **विद्यालय लोगो अपलोड:** अपने स्कूल का लोगो अपलोड करें।
   * **संस्था प्रधान व अध्यापक नाम:** नाम दर्ज करें, जो सीधे मार्कशीट और बारकोड में प्रदर्शित होगा।
   * **मैन्युअल डेटा एडिट व जोड़ें:** किसी भी छात्र के अंक या विवरण सीधे स्क्रीन पर एडिट करें या नया छात्र जोड़ें।
   * **एक्सेल इम्पोर्ट व सैंपल डाउनलोड:** प्रत्येक कक्षा के लिए अलग रेडीमेड एक्सेल टेम्पलेट डाउनलोड करें।

## 🚀 GitHub पर अपलोड और Vercel पर लाइव करने की विधि:

### चरण 1: GitHub पर नई रिपॉजिटरी बनाएँ
1. [GitHub.com](https://github.com) पर लॉगिन करें।
2. ऊपर दाएँ कोने में **"+"** दबाकर **"New repository"** चुनें।
3. Repository name लिखें (उदा. `school-result-portal`), इसे **Public** रखें और **"Create repository"** पर क्लिक करें।
4. आपको रिपॉजिटरी का लिंक मिलेगा (उदा. `https://github.com/your-username/school-result-portal.git`).

### चरण 2: अपने कंप्यूटर से कोड पुश (Push) करें
अपने कंप्यूटर पर टर्मिनल / PowerShell खोलें और यह कमांड चलाएँ:
```bash
cd D:\chating\school_result_portal

# अपना GitHub रिपॉजिटरी URL जोड़ें (your-username की जगह अपना यूज़रनेम लिखें)
git remote add origin https://github.com/your-username/school-result-portal.git

git branch -M main
git push -u origin main
```

---

### चरण 3: Vercel पर 1-क्लिक में लाइव डिप्लॉय करें
1. [Vercel.com](https://vercel.com) पर जाएँ और **Continue with GitHub** से लॉगिन करें।
2. **"Add New..." ➔ "Project"** पर क्लिक करें।
3. आपकी GitHub रिपॉजिटरी (`school-result-portal`) स्क्रीन पर दिखाई देगी, उसके आगे **"Import"** बटन दबाएँ।
4. कोई सेटिंग बदलने की ज़रूरत नहीं है (सभी सेटिंग्स `vercel.json` और `package.json` में पहले से तैयार हैं)।
5. नीचे **"Deploy"** बटन दबा दें!
6. मात्र 30 सेकंड में आपकी वेबसाइट लाइव हो जाएगी और आपको एक मुफ़्त डोमेन मिल जाएगा (उदा. `https://school-result-portal.vercel.app`)!
